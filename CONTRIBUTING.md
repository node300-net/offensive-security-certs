## Grundsätze

1. **Ehrlich bleiben.** Keine erfundenen Preise, Prüfungsformate oder Lernstunden. Jede Aussage braucht einen **Link** oder die Markierung **⚠️ unverifiziert / Schätzung / Ableitung** mit Begründung.
2. **Primärquelle vor Hörensagen.** Anbieterseiten = ✅, Foren/Reddit/Reviews/Aggregator = 🟦 (Einzelmeinung). Kundenzitate auf der Anbieterseite sind **kein** Beleg.
3. **Datum nennen.** Preise ändern sich oft (siehe HTB 12.10.2026). Bei Änderungen den **Recherchestand** im README und in `docs/prices.md` aktualisieren.
4. **Herstellerneutral.** Kein Affiliate-Link, keine Werbesprache. Schwächen gehören in die Steckbriefe.
5. **Keine Exploit-Anleitungen.** Dieses Repo vergleicht Zertifikate – es erklärt nicht, wie man Systeme angreift.
6. **Keine Secrets.** Keine Exam-Flags, Voucher-Codes, persönlichen OSID-Nummern.
7. **Sprache.** Dokumentation auf **Deutsch**; Zertifikatsnamen und Fachbegriffe dürfen Englisch bleiben.
